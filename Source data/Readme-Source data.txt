README for Source Data

1. Overview

The data are organized into ten separate Excel files, with one file corresponding to each figure. Extended Data Figure 1 presents the research workflow and has no separate numerical source data file.

2. Main Figure Source Data

2.1 Source_Data_Fig_1.xlsx

Numerical source data for Figure 1. The file contains annual greenhouse-gas emissions associated with U.S. weapon manufacturing from 2013 to 2050, disaggregated by emission scope and source, and historical emission intensities for six major weapon product categories.

2.2 Source_Data_Fig_2.xlsx

Numerical source data for Figure 2. The file contains emissions associated with domestic arms demand and exports, together with firm-level, demand-channel and product-level emission summaries for 2013–2023.

2.3 Source_Data_Fig_3.xlsx

Numerical source data for Figure 3. The file contains country-level and U.S. state-level emission data, product-level contributions, and order-level international emission-flow data for U.S. weapon exports during 2013–2023.

2.4 Source_Data_Fig_4.xlsx

Numerical source data for Figure 4. The file contains annual emissions associated with representative weapon products during 2013–2023, identified by weapon type, year, company, purchaser and transaction category.

2.5 Source_Data_Fig_5.xlsx

Numerical source data for Figure 5. The file contains projected weapon-related emissions, climate-target comparison pathways, and emissions pathways for selected hard-to-abate sectors.

The comparison with climate-target pathways includes Scope 1, Scope 2 and both upstream and downstream Scope 3 emissions. The comparison with hard-to-abate sectors includes Scope 1, Scope 2 and upstream Scope 3 emissions.

2.6 Source_Data_Fig_6.xlsx

Numerical source data for Figure 6. The file contains sensitivity-analysis results for sectoral allocation, military input coefficients, balancing weights, military-to-civilian emission-intensity ratios, defense-expenditure-to-GDP ratios, arms-import shares and alternative projection approaches.

The emission-intensity analysis includes 64 scenarios for each year during 2013–2023. Relative emission deviations are stored as fractional values and displayed using percentage formatting.

3. Extended Data Figure Source Data

3.1 Source_Data_Extended_Fig_2.xlsx

Numerical source data for Extended Data Figure 2. The file contains annual emissions associated with U.S. domestic arms demand during 2013–2023, identified by year, product category, company and production state.

3.2 Source_Data_Extended_Fig_3.xlsx

Numerical source data for Extended Data Figure 3. The file contains annual emissions associated with U.S. arms exports during 2013–2023, identified by year, product category, company, production state, destination and destination group.

3.3 Source_Data_Extended_Fig_4.xlsx

Numerical source data for Extended Data Figure 4. The file contains weapon-sales data associated with domestic demand and exports, together with firm-level, demand-channel and product-level sales summaries for 2013–2023.

3.4 Source_Data_Extended_Fig_5.xlsx

Numerical source data for Extended Data Figure 5. The file contains order-level export-related emissions by importing country or region and weapon product category during 2013–2023.

These records also support the international emission flows shown in Figure 3c. Extended Data Figure 5 presents the flows separately for six weapon product categories.

4. Data Format and Interpretation

All ten figure-specific files are provided in .xlsx format. Each file contains one worksheet. Files supporting figures with multiple panels contain the corresponding labelled data sections within that worksheet.

Units are specified in the data-section titles and column headings. Units may differ between panels within the same figure. Percentage shares and relative deviations are stored as fractions and displayed using percentage formatting.

Company identifiers such as AF1 and AF2 follow the anonymized company codes used in the manuscript. Each identifier represents a unique company.

The files can be opened using Microsoft Excel or other compatible spreadsheet software.
