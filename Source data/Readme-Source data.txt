README for Source Data Related to the Manuscript

1. Overview

This README provides a brief description of the source data underlying the figures in the manuscript. The original plotting data are compiled in one Excel workbook, "Source data.xlsx", with separate worksheets corresponding to Fig. 1–Fig. 6.

2. Data File and Contents

2.1 Source data.xlsx

- Fig. 1: Annual GHG emissions associated with the U.S. weapon-manufacturing sector from 2013 to 2050, including historical estimates and future projections disaggregated by emission scope and source.

- Fig. 2: Cumulative emissions associated with U.S. domestic arms demand and arms exports, together with firm-level cumulative emissions by procurement or sales channel.

- Fig. 3: Spatial and product-level distributions of cumulative emissions embodied in U.S. arms exports, including order-level bilateral emission flows by weapon type.

- Fig. 4: Annual emission composition of representative weapon systems, disaggregated by year, company, purchaser, and transaction type.

- Fig. 5: Projected arms-related emissions and their comparison with climate-target pathways and selected hard-to-abate sectors.

- Fig. 6: Uncertainty analysis covering the construction and balancing of the military-expanded input-output tables, sector-specific emission intensities, and projections of future arms-related emissions.

3. Data Format and Usage

The source data are provided in .xlsx format and can be opened using Microsoft Excel or other compatible spreadsheet software. The workbook contains the original numerical data used to produce the manuscript figures and is intended to support the transparency, verification, and reproducibility of the reported results.
