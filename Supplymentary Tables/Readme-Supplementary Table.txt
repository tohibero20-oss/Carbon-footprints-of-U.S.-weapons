README for Supplementary Tables Related to the Manuscript

1. Overview

This README provides a brief description of the supplementary tables associated with the manuscript. The data are organized in a single Excel workbook, Supplementary Table-20260912.xlsx, with seven worksheets corresponding to Tables S1–S7. These tables provide supporting emissions data, input–output sector classifications, mappings of military product categories, sectoral and regional concordances for the U.S.–GLORIA MRIO framework, company-level emission-intensity information, and reference mappings used in the study.

2. Data File and Its Contents

2.1 Supplementary Table-20260912.xlsx

- Table S1: Summarizes greenhouse gas emissions reported for selected wars and military conflicts. The table includes the conflict name, greenhouse gas coverage, accounting scope, duration, total emissions, annual average emissions, and references.

- Table S2: Reports annual greenhouse gas emissions for low-income countries from 2013 to 2023. The table provides country names, country codes, regional classifications, and annual emissions in MtCO2.

- Table S3: Provides sector codes and descriptions used in the U.S. input–output economic accounts. Table S3a presents the concordance between the original 402-sector classification and the aggregated 391-sector classification. Table S3b lists the sectoral classification used in the U.S. national input–output tables after disaggregating the six arms-manufacturing sectors.

- Table S4: Provides the mapping between arms-order product items and the six arms-manufacturing sectors. Table S4a maps Department of Defense (DoD) and Foreign Military Sales (FMS) order items to the corresponding arms-manufacturing sectors. Table S4b maps Direct Commercial Sales (DCS) categories and descriptions to the corresponding arms-manufacturing sectors.

- Table S5: Provides the sectoral and regional concordances used to integrate the disaggregated U.S. input–output table into the GLORIA MRIO framework. Table S5a maps the 391 U.S. input–output sectors to the 86 common sectors. Table S5b maps the 120 GLORIA sectors to the same 86 common sectors. Table S5c lists the codes and names of the 86 common sectors. Table S5d maps the 164 GLORIA regions to the 32 aggregated regions used in the study. Table S5e lists the names and acronyms of the 32 aggregated regions.

- Table S6: Reports greenhouse gas emissions, operating costs, and emission intensities for selected military and civilian arms-manufacturing companies across available years. These data are used to compare military and civilian production emission intensities and to parameterize the disaggregation of direct emissions between military and civilian activities.

- Table S7: Provides reference mappings used in the spatial and regional analyses. Table S7a maps countries and organizations to the regional or organizational groups and abbreviations used in the study. Table S7b lists U.S. states and their standard abbreviations.

3. Data Format and Usage

The supplementary tables are provided in xlsx format. Units and variable definitions are provided in the titles and column headings of each worksheet.
